# BAMM — site vitrine

Ouvrez `index.html` dans votre navigateur (double-clic). Aucune installation requise.
Pour un serveur local : `python3 -m http.server 8000` puis http://localhost:8000

Pages : index, probleme, solution, demo, ia, business, equipe.
Les textes sont directement modifiables dans les fichiers .html.
